# 🏢 ERP 프로젝트
> **도메인형 구조를 채택한 효율적인 기업 자산 관리 시스템**
> 프로젝트 기간: 2023.09.13 ~ 2023.11.08 (팀 프로젝트)

## 🛠 Tech Stack
- **Backend:** Java, Spring Boot, Spring Security, MySQL
- **Frontend:** React
- **Infrastructure:** AWS, GitHub
- **Tools:** Postman (API Test & Share)

---

## 📱 담당 기능 및 성과
- **PM & Architecture:** 프로젝트 팀장, DB 설계, 도메인형 폴더 구조 세팅
- **Collaboration Flow:** GitHub 브랜치 전략 수립 및 Pull Request 기반 코드 리뷰 환경 구축
- **Core Logic:** 기본적인 CRUD 공통 모듈 개발, Spring Security 권한 분기 설정
- **External API:** TMDB API를 활용한 데이터 파싱 및 DB 자동 적재 로직 구현
- **DevOps:** AWS RDS 인스턴스 구축 및 로컬 개발 환경(IntelliJ) 연동으로 팀 데이터 정합성 확보

## 💡 깨달은 점
- **아키텍처:** 기존 계층형 구조에서 **도메인형 구조**로 전환하며 프로젝트의 확장성과 가독성을 높이는 경험을 했습니다.
- **협업:** PR 기반의 머지 전략과 Postman 공유를 통해 팀원 간의 개발 싱크를 맞추는 법을 익혔습니다.
- **인프라:** 클라우드 DB(AWS)를 활용해 팀원들과 실시간으로 데이터를 공유하며 개발 생산성을 크게 향상시켰습니다.
- **중재:** 팀원 간의 의견 차이를 조율하며 팀워크를 이끌어가는 리더십을 경험했습니다.
